「結構」四模組(前半週)

① 邊緣偵測 (Edge Detection)

  • 差分起手式:前向/後向/中心差分
  • 一階導數:Sobel / Prewitt
  • 二階導數:Laplacian / LoG
  • 頻率域對偶觀點:DFT
  • Canny 五步驟:高斯模糊 → 梯度 → 非極大值抑制 → 雙閾值 → 連接
  • cv2.Canny(img, low, high)

② Hough Transform

  • 為什麼用 Accumulator 投票機制
  • 直線 HoughLines / HoughLinesP
  • 圓形 HoughCircles
  • 從邊緣圖找幾何形狀的經典方法

③ 形態學處理

  • Erosion 侵蝕(縮小白區)
  • Dilation 膨脹(擴大白區)
  • Opening = erode → dilate(去雜訊)
  • Closing = dilate → erode(填洞)
  • 集合論定義 + OpenCV morphologyEx
  • W9 RPS 膚色 mask 會用到

④ 輪廓 + 形狀特徵

  • CCL (Connected Component Labeling)
  • cv2.findContours + contourArea
  • 形狀度量:面積 / 周長 / 緊密度 / 圓度量 / Aspect Ratio
  • cv2.convexHull / convexityDefects (W9 凸缺陷會用)

「指紋」四模組(後半週)

① 角點偵測

  • Harris:自相關矩陣 + R 函數
  • FAST:周圍 16 點判斷
  • 差別:Harris 數學嚴謹但慢,FAST 啟發式但快

② SIFT + ORB

  • SIFT 四階段:DoG → 精化 → 方向 → 描述
  • 尺度不變 + 旋轉不變
  • ORB (FAST + BRIEF):嵌入式王牌,免費、快
  • cv2.ORB_create 即可用

③ Matching

  • Brute Force cv2.BFMatcher
  • FLANN(大量特徵用)
  • Ratio Test:Lowe 1999 經典過濾錯配
  • m.distance < 0.75 * n.distance

④ RANSAC + Homography

  • 用隨機抽樣 + 共識數,剔除離群點
  • cv2.findHomography(src, dst, cv2.RANSAC)
  • 連 W4 學過的 Homography 與本週特徵點 — 圖片拼接、AR 標記辨識的基礎

本週實作:把古典 CV 跑在 Android 上

W6 的 Chaquopy 框架繼續用,只是 Python 端的演算法升級到本週工具。沒有新作業,但鼓勵把本週每個工具都在 Android 試一遍(把 W6 作業 App 改造)。

實作節奏建議:
  1. 選一個你 W6 完成的 App
  2. 把 process_image 函式換成本週工具(例如 Canny、Hough、形態學任挑兩個)
  3. build + run,看 Android 上的處理結果
  4. 記錄 FPS:Chaquopy 上 Python OpenCV 在中低階手機通常 5-10 FPS

學生檢核表

  • 我能說出 Canny 五個步驟與設計理由
  • 我理解 Hough 為什麼要用 Accumulator 投票
  • 我能用 erosion / dilation / opening / closing 解決雜訊問題
  • 我能用 findContours 抽出形狀並算面積
  • 我能說明 SIFT vs ORB 的差別
  • 我理解 RANSAC 為什麼比直接最小平方更穩
  • 本週至少把一個 Android App 改用古典 CV 工具跑通
