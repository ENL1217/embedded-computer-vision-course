講義 Ch.0–9 重點

Ch.0–1 ｜ 課程定位

  • 為什麼用 Android (普及、設備多、學生熟悉) 而不是 Raspberry Pi / Jetson
  • Chaquopy 是 Android 與 Python 之間的橋樑,讓 Java 可以呼叫 Python 函式
  • Android 模擬器可輔助教學,但實機才能完整測試硬體
  • 循序漸進:先 hello() → 資料傳遞 → NumPy → OpenCV → View,最後才接 CameraX (W9)

Ch.2–3 ｜ Chaquopy 運作機制 + 環境設定

  • Gradle 怎麼打包 Python 套件進 APK
  • Android Studio 安裝、新專案建立、Chaquopy plugin 安裝
  • build.gradle 設定 python.pip 安裝套件
  • ABI filter 設 arm64-v8a + x86_64 (模擬器 + 實機都跑)

Ch.4 ｜ Hello Android + Python

  • 第一個 main.py 函式 hello()
  • Java PyObject result = Python.getInstance().getModule("main").callAttr("hello")
  • 把結果顯示到 TextView

Ch.5 ｜ Java ↔ Python 資料傳遞

  • 傳數字 (Integer / Long / Float)
  • 傳字串
  • 傳 byte[] — 影像處理的關鍵 (W7 W9 一直用到)
  • Python 端用 bytes() 接收

Ch.6 ｜ Python 套件與 NumPy

build.gradle 加 install "numpy"。Python 端 import numpy as np 即用。

Ch.7 ｜ Android 讀圖傳給 Python

  • Android assets 或 SD card 讀圖檔
  • Bitmap → byte[]
  • Python 接 byte[] → np.frombuffer → 矩陣

Ch.8 ｜ OpenCV Python 在 Android 上 ⭐ 本週重點

  • install "opencv-python" (Chaquopy 第一次 build 5-10 分鐘)
  • Python 端 import cv2
  • 跑灰階化、二值化、邊緣偵測等 W3 學過的工具
  • 結果 cv2.imencode 變 JPEG byte[] 回傳 Java

Ch.9 ｜ Android View 與圖片顯示

  • BitmapFactory.decodeByteArray 把 Python 回傳的 JPEG byte[] 變回 Bitmap
  • ImageView 顯示
  • UI Thread 與背景執行緒分工

為什麼選 Chaquopy(教學上的折衷)

Chaquopy 不是效能最佳解。要做正式商業等級高 FPS、低延遲 App,通常會選:

  • Java / Kotlin + OpenCV Android SDK
  • TensorFlow Lite
  • MediaPipe
  • ONNX Runtime Mobile

但本課程教學目標是「理解完整流程」,不是極致效能。學生先用熟悉的 Python 跑通完整管線,後續要改 SDK 就有方向。W11 YOLO 之後就會走 Java TFLite,把效能補上。
