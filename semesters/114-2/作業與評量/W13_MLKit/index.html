W13 作業 · Part III · 五範式收官

ML Kit 三 API 整合 + 五方法對照

用 Google ML Kit 的 9 大 API 任挑 3 個整合到 App,其中至少一個用於 RPS。產出 W9-W13 完整對照表,看完整個工具光譜。

一、作業目標

體驗「production-ready」工具棧的開發速度。挑 3 個 ML Kit API 整合到一個 App,其中至少 1 個用於 RPS。完成 W9-W13 五範式完整對照表。

二、作業內容

必做:整合 3 個 ML Kit API

從以下 9 個任挑 3 個(至少 1 個用於 RPS 或手勢相關):

  • Face Detection
  • Text Recognition (OCR)
  • Barcode Scanner
  • Image Labeling(可用 Custom 訓練自己的標籤)
  • Object Detection & Tracking
  • Pose Detection(33 點全身骨架,可做 RPS)
  • Selfie Segmentation

必做:五範式對照表

三、加分項

  • (+2) Custom Image Labeling:訓練自己的 RPS 標籤
  • (+2) 比較 on-device vs Cloud(同一 API 跑兩種模式測延遲)
  • (+3) 用 ML Kit + 你前面學過的方法(例如 ML Kit Pose + W12 彎曲度)做更穩 RPS

四、繳交內容

  • 30 秒測試影片:展示 3 個 ML Kit API 的功能
  • 簡易報告:含五範式完整對照表 + 對「選工具」的觀察
  • Android 專案(GitHub repo)

五、注意事項

  • ML Kit 是 production-ready 但不適合所有任務:它的 Image Labeling 是通用的,RPS 需要 Custom 才行
  • Pose Detection 33 點 vs MediaPipe Hands 21 點 — 一個全身、一個專手
  • on-device 預設免費,Cloud 要 Firebase + 計費
  • App size 會被 ML Kit 模型撐大,可以用「需要時下載」模式
