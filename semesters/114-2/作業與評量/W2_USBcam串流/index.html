USB Camera 即時串流

建立 Colab + Local Runtime + 本地 webcam 即時串流環境。整門課所有「即時影像實驗」的基礎建設,本週確認可運作。

一、作業目標

建立 Colab + Local Runtime + 本地 webcam 即時串流環境,確認可運作。這是後面 W3 影像濾波、W9-W13 RPS 系列等所有即時實驗的基礎。

二、作業內容

  1. 依 W2 補充教材 4 步驟建置 Local Runtime
    • 建 Conda 環境 colab_cv
    • 安裝 opencv-python + jupyter_http_over_ws
    • 啟動本地 Jupyter (含 CORS 設定)
    • Colab 「連線至本地執行階段」
  2. 用 Colab 連到本機 Jupyter — 右上角圖示變綠色勾勾即代表成功
  3. 跑底層除錯腳本(補充教材 ❹),列出可用攝影機 index
  4. 用 cv2.VideoCapture(0, cv2.CAP_DSHOW) 開啟 webcam 查看畫面

三、繳交內容

串流成功畫面的截圖(畫面要有自己),確認功能正確。

  • 截圖中可看到 Colab notebook 介面
  • 畫面有自己 (確認 webcam 真的有讀到本地相機)
  • 右上角 Colab 連線圖示是「綠色勾勾的小電腦」

四、注意事項

  • 執行前 關掉所有相機程式 (OBS、Zoom、Teams、Discord)
  • 瀏覽器網址列若有相機授權記錄,點 ⓘ 關閉
  • Windows 用戶強烈建議用 DSHOW backend: cv2.VideoCapture(0, cv2.CAP_DSHOW),避免預設後端慢
  • numpy 鎖 pip install "numpy<2",避免相容性問題
  • port 8888 被占就改 8889 或 8890
  • 若無法讀到攝影機,跑除錯腳本看 webcam index 是 0、1 還是 2
  • 有問題可先問 Colab 內建 Gemini,再問老師
