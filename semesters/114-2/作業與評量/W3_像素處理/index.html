Lab 1 ｜ 夜間監視器影像 Gamma 矯正

情境

你負責維護社區安防系統,某支監視器在夜間拍出的畫面幾乎全黑,只有極微弱的路燈光影。請勿使用單純加法(會讓背景雜訊泛白),必須使用 Gamma Correction 非線性地提亮暗部細節,找出畫面中隱藏的人物輪廓。

步驟

  1. 讀入欠曝影像,計算並顯示直方圖,確認直方圖極度左偏
  2. 實作 Gamma 矯正函式(注意 float32 轉換與 uint8 截斷)
  3. 試驗 γ = 0.1, 0.3, 0.5, 0.7,比較各 γ 值的視覺效果與直方圖變化
  4. 建立 LUT 版本 (cv2.LUT),用 time.perf_counter() 測量速度差異

核心公式

output = 255 * (input / 255) ** gamma
# gamma < 1 → 提亮暗部
# gamma = 1 → 不變
# gamma > 1 → 壓暗

Lab 2 ｜ 產線視覺檢測影像品質診斷

情境

產線視覺檢測機台因廠房環境光源不穩定,導致拍出來的零件圖片時而過曝、時而曝光不足、時而低對比。請設計一套自動影像品質診斷與修復程式。

步驟

  1. 讀入病態影像(過曝、欠曝、低對比)
  2. 計算每張影像的直方圖並繪製,寫出文字診斷結果
  3. 分別套用 cv2.equalizeHist() 和 CLAHE,比較兩者的效果
  4. 刻意把 CLAHE 的 clipLimit 設為 40,觀察雜訊放大的後果,再調回 2.0

關鍵函式

import cv2
import numpy as np

# 全域直方圖均衡
img_eq = cv2.equalizeHist(gray)

# 局部直方圖均衡 (CLAHE)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
img_clahe = clahe.apply(gray)
