空間處理:插值、透視校正、相機校準

從像素值處理轉到像素位置處理。三個 Lab 涵蓋:插值法品質比較、Homography 透視校正、棋盤格相機校準。

Lab 1 ｜ 插值法演算法比較 (Interpolation)

目標

觀察不同數學插值演算法對影像放大後的品質影響。

步驟

  1. 選取一張小像素圖(例如圖標或文字截圖,越小越明顯)
  2. 分別使用以下三種方法將圖片放大 4 倍(亦可參考 GitHub 上其他方法):
    • Nearest Neighbor (最近鄰插值)
    • Bilinear (雙線性插值)
    • Bicubic (雙立方插值)
  3. 將三張結果圖並列,觀察邊緣鋸齒與模糊感

關鍵程式

img_nn   = cv2.resize(img, None, fx=4, fy=4, interpolation=cv2.INTER_NEAREST)
img_bi   = cv2.resize(img, None, fx=4, fy=4, interpolation=cv2.INTER_LINEAR)
img_bc   = cv2.resize(img, None, fx=4, fy=4, interpolation=cv2.INTER_CUBIC)

繳交

展示結果圖,並用 50 字內描述你觀察到的差異。

Lab 2 ｜ 文件透視校正 (Perspective Correction)

目標

利用單應性矩陣 (Homography) 將傾斜拍攝的文件轉為正面俯視圖。

步驟

  1. 拍攝:用手機拍攝一張放在桌面上的學生證(需有明顯傾斜角度)
  2. 標記:手動找出文件四個角落在原圖中的座標 src_pts
  3. 計算:定義輸出圖的長寬,設定對應的四個正面座標 dst_pts
  4. 轉換:使用 findHomography 計算矩陣,並透過 warpPerspective 產出矯正後的影像

關鍵程式

import cv2
import numpy as np

src_pts = np.array([[x1,y1],[x2,y2],[x3,y3],[x4,y4]], dtype=np.float32)
dst_pts = np.array([[0,0],[W,0],[W,H],[0,H]], dtype=np.float32)

H, _ = cv2.findHomography(src_pts, dst_pts)
result = cv2.warpPerspective(img, H, (W, H))

繳交

  1. 原始傾斜圖(含標記點)
  2. 矯正後的正視圖

Lab 3 ｜ 相機校準與影像校正

作業目標

掌握相機內參矩陣(Intrinsic Matrix)K 與畸變係數(Distortion Coefficients)D 的物理意義。透過棋盤格校準法,學習如何將受鏡頭畸變影響的原始影像,校正為符合針孔相機模型的影像。

實驗內容

  1. 資料採集:自行列印或開啟棋盤格圖檔,使用相機從不同角度拍攝至少 10-15 張照片
  2. 參數計算:撰寫程式碼識別棋盤格角點,求出相機內參矩陣 K 與畸變參數 D
  3. 即時校正:將參數套用於即時影像串流 (Camera Stream),輸出校正後 (Undistorted) 的畫面
  4. 參數擾動實驗:手動修改校準後的參數(如改變焦距 fx、主點座標或畸變係數),觀察影像產生的變異

關鍵程式

import cv2
import numpy as np

# 1. 抓棋盤格角點 (對每張照片做)
ret, corners = cv2.findChessboardCorners(gray, (9,6), None)

# 2. 校準
ret, K, D, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, imgpoints, gray.shape[::-1], None, None)

# 3. 即時校正
undistorted = cv2.undistort(frame, K, D)

繳交

  • 參數文件:包含內參矩陣 K (3×3) 與畸變向量 D 的數值資料
  • 錄製影片:展示原始與校正影像的對比。可嘗試「手動調整參數」後畫面變化的過程
  • 實驗心得:描述影像串流產生的具體物理變異現象
提示:
  • 校準時請確保棋盤格涵蓋畫面邊緣,以獲得更準確的畸變參數
  • 若相機較高級會自動對焦,請手動關閉(因為會影響相機的校準參數)

參考資源
