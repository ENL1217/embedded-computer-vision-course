Android Python OpenCV 練習

一、作業目標

把 W6 學到的 Chaquopy + Python OpenCV 完整跑通一次:從 Android 端讀圖、傳給 Python 處理、再把結果顯示回 Android UI。整門課所有 Android 端的 CV 實作都從這個基礎延伸。

二、作業內容

執行完成 Chaquopy 講義第 8 章,確認可在 Android 模擬器(或實體手機)上完成:

  1. 可讀圖 — 從 assets 或 SD card 讀出 Bitmap
  2. 可透過 Python OpenCV 處理圖片 — 至少跑一個處理(例如灰階化、二值化、邊緣偵測任挑)
  3. 可顯示處理後的圖片 — 顯示在 ImageView

核心程式架構

// Java 端
byte[] imageBytes = readBitmapAsBytes(...);
PyObject result = Python.getInstance()
    .getModule("main")
    .callAttr("process", imageBytes);
byte[] processedJpeg = result.toJava(byte[].class);
Bitmap bmp = BitmapFactory.decodeByteArray(
    processedJpeg, 0, processedJpeg.length);
imageView.setImageBitmap(bmp);
# Python 端 main.py
import cv2
import numpy as np

def process(image_bytes):
    arr = np.frombuffer(bytes(image_bytes), np.uint8)
    img = cv2.imdecode(arr, cv2.IMREAD_COLOR)

    # 你的處理 — 灰階 / 二值化 / Canny 任挑
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

    ok, buf = cv2.imencode('.jpg', gray)
    return buf.tobytes()

三、繳交內容

Android 模擬器或手機畫面截圖,需含:

  • App 主畫面
  • 原圖 + 處理後的圖(都顯示在 ImageView)
  • 明顯看得出有處理過(例如灰階看得出顏色掉了)

四、注意事項

  • 第一次 build 安裝 opencv-python 大約要 5-10 分鐘(Chaquopy 編譯),請耐心等
  • build.gradle ABI filter 建議設 arm64-v8a 和 x86_64(模擬器和實機都能跑)
  • Python 套件版本鎖定 numpy 和 opencv-python 即可(讓 Chaquopy 自選相容版本)
  • App crash 看 Logcat 過濾 python 關鍵字,會看到 Python traceback
  • 用 Git 把專案備份到 GitHub (參考 Android Git 版本管理)
  • 有問題可先問 Colab 內建 Gemini 或老師
