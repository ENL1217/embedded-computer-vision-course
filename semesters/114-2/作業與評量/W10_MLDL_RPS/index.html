W10 作業 · Part III · 同題目換 AI 做

用 ML / DL 完成猜拳辨識

挑一條(或多條)路線,訓練 + 部署 + 跟 W9 規則法對比。看到 60-80% → 90%+ 的提升,並理解代價。

一、作業目標

體驗「特徵由演算法從資料學出來」比手刻好多少。完成至少一條路線(B/C/D 任挑),並產出 Confusion Matrix 跟 W9 規則法對比。

二、作業內容

必做(任挑一條)

路線 B:HoG + SVM(部署到 Android Chaquopy)

  1. Colab 訓練 HoG+SVM 模型,存成 hog_svm_rps.pkl
  2. Android 端用 Chaquopy 載入 .pkl(joblib.load)
  3. 跑即時 RPS 辨識
  4. 產出 Confusion Matrix

或 路線 C/D:Tiny CNN / MobileNetV2(部署到 Colab Local Runtime)

  1. Colab 訓練,存 .tflite
  2. Colab Local Runtime + 本地 webcam 即時推論
  3. 產出 Confusion Matrix

必做:對比表

跟 W9 規則法對比,至少含:

  • 正確率(整體 + 每類)
  • 推論延遲(ms / frame)
  • 模型大小
  • 失敗 case 各 1 個

三、加分項(任選)

  • (+2) 同時跑路線 B + C + D,三方法對比
  • (+2) 自己拍 RPS 資料集(每類 50+ 張)取代教材附的
  • (+2) 跑 Data Augmentation 並對比有 / 無 augmentation 的差異
  • (+2) 在 Android Chaquopy 上整合 W9 規則法 + W10 ML 投票

四、繳交內容

  • 30 秒測試影片:展示即時 RPS,標出正確率
  • .doc / .pdf 簡易報告:含 Confusion Matrix + 與 W9 對比表 + 心得
  • Colab notebook 或程式碼

五、注意事項

  • scikit-learn 鎖 1.4.0:Colab 與 Chaquopy 都 pin scikit-learn==1.4.0,避免版本不一致
  • NumPy 鎖 <2:Local Runtime 端
  • 路線 C/D 不能走 Chaquopy 是因為 tflite-runtime 沒 cp310 wheel(已知工程坑)
  • 第一次訓練 GPU runtime 可能要等 Colab 排隊
  • 共用模型 (shared/assets/models/) 是預訓練版,可直接拿來驗證 pipeline
