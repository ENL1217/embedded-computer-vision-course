本週三條路

路線 B｜傳統 ML

  • HoG + SVM
  • 手工特徵 + 學習式決策邊界
  • 部署:Android Chaquopy
  • 正確率預期 80-90%
  • 模型很小 (~50 KB)

路線 C｜深度學習

  • Tiny CNN 自訓
  • 特徵與決策邊界都由資料學
  • 部署:Colab Local Runtime + Webcam
  • 正確率 85-92%
  • 模型約 8 MB

路線 D｜遷移學習

  • MobileNetV2 Transfer Learning
  • 用大資料集預訓練特徵 + RPS 微調
  • 部署:同上
  • 正確率 92-97%
  • 模型 8.9 MB

研究 vs 功能實作(研究生最該分清的事)

本週是整門課第一次正式把「研究方法論」滲透進教學。從 W10 起,每週都會要求學生:
  • 至少報告一個評估指標(不只 accuracy)
  • 至少對比一個 baseline(本週 baseline = W9 規則法)
  • 含 Confusion Matrix
功能實作研究級報告
目標跑得起來跟世界對話
正確率「我看起來還行」定量 + Confusion Matrix + 失敗分析
實驗跑一次就交多 seed + 區間估計
對比無跟 baseline / SOTA 比
輸出能跑的 APK能投 paper 的報告

兩種部署平台(工程取捨)

本週的工程小發現:不是所有 ML/DL 模型都能直接放上 Chaquopy。

路線 B 部署:Android Chaquopy ✓

  • sklearn 有 cp310 wheel,可直接裝
  • build.gradle 加 install "scikit-learn==1.4.0"
  • 用 joblib.load 載入 .pkl
  • 真實 on-device 推論

路線 C/D 部署:Colab Local Runtime

  • tflite-runtime 沒 cp310 wheel → Chaquopy 路線斷
  • 改走 Colab Local Runtime + 本地 webcam
  • W2 已建好的環境直接用
  • 缺點:不是真嵌入式部署 (W11 走 Java TFLite 補回來)

學生看到這個取捨後,能理解「選工具不是看最潮,是看真的能跑」。
