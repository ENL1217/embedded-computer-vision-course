ML Kit Vision 9 大 API

👁 Face Detection

臉部偵測 + landmark + 表情(笑、眨眼)

📝 Text Recognition (OCR)

多國語言文字辨識 + 區塊結構

📊 Barcode Scanner

QR code、EAN、UPC 等所有條碼

🏷️ Image Labeling

447 個通用標籤(可自訂 Custom)

📦 Object Detection

通用物件 + Tracking

🧍 Pose Detection

全身 33 點 landmark(比 MediaPipe 更多點)

✂️ Selfie Segmentation

人像分割(背景虛化、換背景)

🔍 Smart Reply

(非 Vision) 自動回覆建議

🌐 Translation

(非 Vision) 即時翻譯,on-device

on-device vs Cloud Trade-off

ML Kit 部分 API 有 on-device 與 Cloud 兩種模式:

on-deviceCloud
網路不需要需要
速度毫秒級百毫秒+ 網路延遲
準確率中較高
隱私影像不離手機影像送到 Google
成本免費API 計費
適用即時互動、隱私應用批次處理、高品質離線分析
